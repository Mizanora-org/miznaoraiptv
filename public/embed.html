Mizanora IPTV ka poora system kisi bhi website mein lag sakta hai. Neeche diya gaya 2-line snippet copy kar ke apni HTML mein paste karo — plans, live TV channels, order form aur free trial khud render ho jayenge. API CORS-open hai (Access-Control-Allow-Origin: *), is liye kisi bhi domain se call chalti hai.

⚡ 2-Line Quick Embed

<div id="mizanora-widget"></div>
<script src="https://miznaoraiptv.vercel.app/embed.js"
        data-mz-target="#mizanora-widget"
        data-mz-widget="plans"        <!-- plans | channels | order | trial | plans,channels -->
        data-mz-api="https://miznaoraiptv.vercel.app"
        data-mz-theme="dark"          <!-- dark | light -->
        defer></script>

Widget types: plans channels order trial — comma se combine karo (e.g. plans,channels,order).

🧾 REST API Reference — /api/embed

MethodEndpointAuthKya return hota hai
GET/api/embed?action=configPublicBrand, plans, prices, JazzCash, support, protocol URLs (player_api/get.php/xmltv/portal)
GET/api/embed?action=channels&limit=80PublicLive channels + playUrl (/ch/:slug HLS)
GET/api/embed?action=movies&limit=48PublicIMDb movies catalog (poster, rating, year)
GET/api/embed?action=series&limit=36PublicIMDb series catalog
POST/api/embed?action=orderPublicBody: {name, whatsapp, planId, audience, txnId} → order + JazzCash payment info
POST/api/embed?action=trialPublicBody: {email, whatsapp} → free 1-day Xtream credentials (m3u + epg)
POST/api/embed?action=reseller/registerPublicSelf-serve reseller signup → code + API key + starter credits
GET/api/embed?action=order-status&id=…PublicOrder tracking
GET/api/embed?action=healthPublicService health

🖥️ cURL Examples

curl "https://miznaoraiptv.vercel.app/api/embed?action=config"

curl "https://miznaoraiptv.vercel.app/api/embed?action=channels&limit=20"
