Step 1 — Firebase project mizanoranet tayar karo

  1. Authentication → Sign-in method → Google aur Email/Password dono Enable karo.
  2. Authentication → Settings → Authorized domains mein apna domain add karo: miznaoraiptv.vercel.app (+ preview domains).
  3. Realtime Database → Create database → Rules tab mein repo ka firebase/database.rules.json paste kar ke Publish karo. Is mein admin lock already hai: muaaziqbal.vip@gmail.com (email_verified).
  4. Web app config already code mein hai (public/assets/js/firebase-client.js): project mizanoranet, RTDB https://mizanoranet-default-rtdb.firebaseio.com.

Step 4 — Channels manage karo

  • Admin → Channels: add/edit/delete/reorder; priority groups (🇵🇰 Top → 🕌 Islamic → 🎭 Drama → 📰 News → 🎬 Movies → 🏏 Sports…) auto Xtream groups banate hain.
  • Har channel ka apna data/streams/*.m3u8; GitHub push se directly repo mein publish kar sakte ho (Admin → Settings → GitHub token + repo Mizanora-org/miznaoraiptv).
  • API se: admin/channels, admin/channel/create|update|delete.

Step 5 — Xtream users (web + apps)

  • Users site par Google/Gmail login karke 1 FREE Xtream server claim karte hain (Xtream Vault) — M3U + EPG links auto.
  • Admin UI se: Xtream & PRO Users → 1-day trial / +30 days / set plan.
  • API se (apna panel): admin/xtream-accounts • admin/xtream/create • admin/xtream/update • admin/xtream/renew {days} • admin/xtream/suspend|activate • admin/xtream/delete.
curl -X POST "https://miznaoraiptv.vercel.app/api/panel" -H "x-api-key: mzk_YOUR_KEY" \

Step 6 — MAG / Stalker (MAC) clients

  • MAG box ka MAC address register karo — do tareeke:
    • Reseller API: reseller/client-create with "mac":"00:1A:79:AA:BB:CC"
    • Admin API: admin/xtream/update with {"username":"…","mac":"…"}
  • List dekho: admin/stalker/list (Xtream + panel clients dono se MAC wale).
  • STB mein portal daalo: https://miznaoraiptv.vercel.app/portal.php (ya /stalker_portal/server/load.php). Handshake → token → channels. Demo MAC: 00:1A:79:00:00:01.

Step 7 — Resellers, credits & orders

  • Self-serve: reseller khud /reseller se signup karta hai → RS-XXXXXX code + mzr_ API key + 3 starter credits.
  • Admin: admin/resellers, admin/credits-topup (JazzCash 0306-2015326 verify karke), admin/reseller-create/update.

Step 10 — Security checklist

  • ✅ RTDB rules publish kiye (admin = muaaziqbal.vip@gmail.com, email_verified).
  • ✅ FIREBASE_DATABASE_SECRET, MIZANORA_SIGNING_SECRET set + kabhi leak nahi kiye.
