📡 Mizanora IPTV — API Reference

🏠 Home🔌 Embed API🛡️ Admin Guide🏪 Reseller Panel⚙️ Admin

Apna panel bana lo — hamari APIs par. Mizanora IPTV teen levels ki APIs provide karta hai. Har protected API key se chalti hai, to aap apni website/app/panel mein key dal kar Xtream users, MAG/Stalker clients, channels, orders — sab manage kar sakte ho.

⚠️ Convention: GET requests mein ?action=… query mein; POST requests mein "action": "…" JSON body mein. Base URL: https://miznaoraiptv.vercel.app

🔑 Key types

🛡️ Admin API key mzk_…

Full panel control via API: Xtream users, Stalker MACs, channels, resellers, orders, settings. Banati hai Admin Panel → API Keys ya admin/api-key-create. Sirf hash store hota hai.

Authorization: Bearer mzk_… ya x-api-key: mzk_…

🏪 Reseller key mzr_…

Reseller ke apne clients manage karne ke liye (create/renew/suspend, MAC clients, finance). Signup par milta hai: reseller/register.

x-api-key: mzr_…

👤 Sessions mzp_…

Owner PIN session (12h HMAC) — admin/pin-login. Firebase Google/Email ID token bhi chalega: Authorization: Bearer <idToken>

admin/me se verify karo

2️⃣ Reseller API — /api/panel key: mzr_…

Header: x-api-key: mzr_… (ya body mein apiKey + code). POST body mein "action".

ActionKya karta hai
reseller/logincode + apiKey/password se dashboard session
reseller/clientsApne saare clients (Xtream + MAC) list
reseller/client-createNew client — {name, days, mac?, planId, connectionFee}. MAC dene se Stalker/MAG client banta hai. 1 credit = 30 din
reseller/client-renew / client-suspend / client-blockRenew / suspend / block client
reseller/secure-linkSigned /s/<token> playback link (HMAC, 15 min)
reseller/stats / reseller/finance / reseller/ledgerRevenue, credits, payments ledger
reseller/pricing-set / reseller/payment-recordApni selling price set karo / client payment record karo
curl -X POST "https://miznaoraiptv.vercel.app/api/panel" \
  -H "x-api-key: mzr_YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"action":"reseller/client-create","name":"MAG Box","mac":"00:1A:79:AA:BB:CC","days":30}'
