3. Xtream, M3U and EPG apps

Create a trial or client first, then use its returned credentials in IPTV Smarters, TiviMate or another compatible player.

Connection formats

  • Xtream: server origin + username + password.
  • M3U: get.php URL with type=m3u_plus&output=m3u8.
  • EPG: authenticated xmltv.php URL.
  • MAG/Stalker: assign the MAC in admin/reseller panel and use /portal.php.

4. Import M3U playlists and XMLTV guides

  1. Open Owner Admin → Channels.
  2. Choose a local .m3u/.m3u8 file or paste its HTTPS URL.
  3. Select Free/PRO defaults. Matching IDs update; new channels receive stable unique stream IDs.
  4. Enable linked EPG import when the playlist has x-tvg-url.
  5. For standalone EPG, open Admin → EPG Guide and import .xml/.xmltv or a remote URL.
  6. Match each channel's EPG ID with XMLTV channel id or tvg-id.
Only import playlists and EPG sources you are authorized to use. A playlist/metadata record is not proof of stream rights or availability.

5. Reseller API integration

Dealers can use the visual reseller panel or automate the same actions with an mzr_ key. Keep that key in server environment variables.

Node.js backend example

Common actions: reseller/me, clients, client-create, credentials, client-renew, client-suspend, client-delete, payment-record, pricing-set, ledger, key-rotate. Full machine-readable index: /api/panel?action=help.

Never put mzr_ or mzk_ keys in public JavaScript. Browser → your backend → Mizanora API is the safe integration pattern. Owner mzk_ keys have full admin privileges.

6. Vercel + Firebase deployment

  1. Import the repository with Framework Other, Node 20+, no build command; static output is public.
  2. Add FIREBASE_DATABASE_URL and sensitive FIREBASE_SERVICE_ACCOUNT_JSON.
  3. Set strong, different MZ_OWNER_PIN, MZ_SESSION_SECRET and MZ_STREAM_SECRET.
  4. Enable Firebase Google Auth, add your Vercel/custom domains to Authorized domains, and publish firebase/database.rules.json.
  5. Redeploy, then check /api/embed?action=health.

Required health signals: configuredServiceAccount: true and durableServerWrites: true. Do not rely on serverless /tmp for customer data.

7. Troubleshooting

Intro plays but the channel does not

Check upstream availability, HTTPS mixed content and the provider's browser CORS policy. Xtream apps may work even when browser playback is blocked.

Movies/episodes say Metadata only

Configure a licensed MP4/HLS URL in Admin. IMDb metadata alone is not a video stream.

Guide has channel info but no timed programmes

Import XMLTV and verify EPG IDs. Use Admin → EPG Guide refresh for remote sources.

Vercel saves fail

Check service-account JSON, private key newlines, RTDB URL and Firebase permissions, then redeploy.

Reseller key stopped working

Key rotation revokes the previous key immediately. Update your backend secret.
